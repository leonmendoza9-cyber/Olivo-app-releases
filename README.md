# Olivo: actualizaciones del programa

Canal publico exclusivo para distribuir instaladores firmados de Banco de Germoplasma-INIA / Coleccion de Olivo.

## Estado

Canal creado. Aun no hay instaladores ni versiones descargables publicados.

## Descargas futuras

Los instaladores se publicaran en [Releases](../../releases), junto con su firma y el manifiesto `latest.json` que consulta el aplicativo.

El codigo fuente no se aloja en este repositorio. No se incluyen bases de datos, evaluaciones, pasaportes, usuarios, credenciales ni claves privadas.

Las actualizaciones cambian el software. La informacion de trabajo permanece en cada PC y no se sincroniza con este repositorio.
